📖 Cara Penggunaan
  1. Upload PDF: Buka menu "Upload SKAKPT" dan drag & drop semua file PDF SKAKPT guru
  2. Proses File: Klik "🚀 Proses Semua File" untuk mengekstrak data
  3. Lihat Rekap: Buka menu "Rekap TPG" untuk melihat tabel format TPG
  4. Edit Manual: Aktifkan "Mode Edit" untuk koreksi data langsung di tabel
  5. Export: Klik "📥 Export Excel TPG" untuk download file Excel siap cetak
📝 Data yang Diekstrak
Dari PDF SKAKPT, sistem akan mengekstrak:
  • ✅ Nama Lengkap
  • ✅ NIP (dari NRG/NUPTK/NPK - disesuaikan)
  • ✅ Golongan / Ruang
  • ✅ Gaji Pokok
  • ✅ Gaji Pokok Setelah Pajak (= Jumlah Bersih)
  • ✅ PPH 21 (dihitung otomatis = Gaji Pokok - Gaji Setelah Pajak)
  • ✅ NPWP
  • ✅ No. Rekening
  • ✅ Nama Pada Rekening
  • ✅ Nama Bank
  • ✅ Mata Pelajaran Sertifikasi
  • ✅ Lokasi Tugas
